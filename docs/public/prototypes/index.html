逐页设计说明

01主播放窗打开 →
布局全幅视频面；顶部渐变元信息条（logo/片名/状态 pill/工具钮）；底部悬浮 OSC = 整宽 seek 条（缓冲段可视）+ 按钮行（传输控制 · 音量 · 倍速 · A-B · 字幕 · 截图）。
交互OSC 2.5s 无输入自动隐藏，悬停/拖动/浮层/暂停时钉住；seek 悬停预览、松手提交；全部操作有等价快捷键（与实现一致）。
状态播放中暂停 · 中央大播放键缓冲 · 事件驱动空态 · Open a file
02播放列表打开 →
布局右滑入浮层：左导航（队列/循环/随机）+ 队列视图；当前行橙色高亮 + EQ 动画，行尾时长与行操作。
交互P 呼出；点选即播、x 移除、悬停浮现「下一首播放/移除」、拖拽排序；N/Shift+N 步进，越界只 Toast。
状态播放中 · EQ 动画暂停中 · EQ 停止+徽标空态 · 入队引导海报
03设置面板打开 →
布局居中模态：左 tab 导航（通用/播放/字幕/网络/关于）+ 右内容区；字幕组含字体·字号·同步偏移与下载/翻译端点。
交互改动即写本地偏好，无「应用」概念；esc/遮罩关闭；字号按屏幕高度缩放（多 DPI 等观感）；密钥仅存本机。
状态通用 · 启动/外观网络 · 本地优先无源=默认端点未配置 · 中性提示不臆造
04媒体库 前瞻 · v1.0打开 →
布局侧栏分类（续播/已看完按进度自动归位）+ 海报网格 + 搜索框；P2P 条目额外标注下载态。
交互点击卡片即插入队首播放；搜索即时过滤；空态保留完整导航不弹窗导流。
状态有库 · 网格浏览无结果 · 保留语境给出口空库 · 引导加库
05字幕翻译面板打开 →
布局主窗 + 可拖动翻译浮层：语言选择 · 整轨进度 · 译文预览（在线/队列/失败三态）。
交互按需翻译：未到行不预译，拖动跳转即补译该行；服务由用户显式配置端点（OpenAI 兼容）。
状态已配置 · 进度可视未配置端点 · 配置引导
