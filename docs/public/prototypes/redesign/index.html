桌面播放器原型 v2：重设计说明

Design Read：以 redesign-preserve 口径重读四页桌面应用稿（受众 = 本地优先播放器的桌面用户；语境 = 深色媒体应用）， 语言收敛为「克制原生的桌面应用感」：中性分层 + 单一信号橙强调 + tabular 等宽时间码；铬层零渐变、零发光。
DESIGN_VARIANCE 5（match existing）/ MOTION 4（match+1，hover 与状态反馈 150ms）/ VISUAL_DENSITY 6（应用密度，字号地板 11px）

旧稿丑点清单（重设计依据）

  1. 渐变字与渐变标：wing 品牌位 linear-gradient 橙色渐变在四页与关于位共 5 处，主播放窗另有顶栏渐变遮罩叠加三层 radial 渐变「光带」。
  2. 占位媒体全是渐变：视频面、列表缩略图、海报卡全部用 radial-gradient 云带伪装画面，一屏可叠 6 个渐变图块。
  3. em-dash 入文案：「Tears of Steel (2012) — 1080p」（播放列表行、nowbar、媒体库卡）与「未配置 — 默认不下载」等端点行共 7 处。
  4. 字符当图标：「▶ 播放中」pill 用几何字符代替图标。
  5. 中点分隔过密：「MP4 · 1080p · 52.0 MB」一行 3 至 5 个 ·，元数据行几乎全靠中点串。
  6. 发光与光晕：主播放键 4px 橙色光环、搜索框蓝色外光晕、进度手柄光晕。
  7. 字号过小、层级靠灰度：大量 10/10.5px 文本低于 12px 正文地板；标题与正文同字号，层级几乎全靠颜色深浅。
  8. 危险色语义错位：红色 dangerbtn 用于「编辑/添加」中性操作共 7 处，销毁语义被稀释。
  9. 操作仅悬停可达：播放列表行操作 hover 才 display，键盘用户触达不了。
  10. 无限动画无守卫：EQ 三柱循环动画未包 prefers-reduced-motion。
  11. 圆角不成体系：14/10/7/999/5/26px 混用且无成文规则。
  12. 状态信息重复堆叠：播放窗同屏出现顶栏三 pill、顶部状态条、OSC 分辨率 chip 共五处状态，互相抢注意。
  13. 仅暗色一版：没有亮色主题，无法覆盖亮环境使用。
  14. 强调色边界模糊：天蓝既是网络语义又当 docbar 链接、快捷键着色，装饰性扩散。

改了什么，为什么

全局（assets/proto.css v2）

  • 渐变清零：wing 改纯色橙块深墨字；媒体占位改纯色块 + 细线胶片字形。旧稿的渐变都在伪装「质感」，纯色块反而更接近真实播放器的内容占位。
  • token 三层重建：原始层（橙/蓝/语义色档）到语义层（surface/line/text 0-3）到组件层，组件不吃裸 hex；亮暗两主题同一套语义 token 翻转。
  • 对比度按 AA 校过：元信息档暗底 6.0:1、亮底 4.8:1；主按钮恒为橙底深墨字（6.5:1），亮色主题不换白字（白字对橙只有 2.6:1）。
  • 字号地板 11px：废除 10/10.5px；层级改由「13px/500 标题 + 12px 正文 + 12px tabular 等宽数字」承担，不再全靠灰度。
  • 圆角成文：面板 10 / 控件 7 / 徽标 pill / 图标钮圆形，写进 token 注释。
  • 动效守卫：EQ 与 spinner 包 prefers-reduced-motion，减少动效下立即静止。

主播放窗

  • 假画面改真占位：三层渐变「光带」改为纯黑画面 + 字幕行。播放器的视频区本该是内容，占位阶段一块纯黑加一行字幕比伪造的渐变画面更诚实，也更像播放器。
  • 状态归一处：顶栏三 pill + 状态条 + OSC 分辨率 chip 五处收敛为两处：顶栏居中只放片名，状态条集中「正在播放 + 时间 + P2P 45%」，分辨率留在 OSC（它本来就是播放参数）。
  • 去光环：主播放键删 4px 光环，播放/暂停态用底色翻转表达；进度手柄删光晕，改 2px 深色描边保证在任何画面上可见。
  • 外壳随主题（v2.1 修订）：悬浮 OSC 属控制栏外壳，亮色主题下改真浅色面板（深字浅底），不再沿用 v2 的「恒深」口径；仅视频画布与其上的字幕保持内容层恒黑。

播放列表

  • 文案去 dash、中点限流：「Tears of Steel (2012) — 1080p」改空格连接；「MP4 · 1080p · 52.0 MB」改「MP4 1080p · 52.0 MB」，每行至多一个中点。
  • 行操作可达：hover-only display 改为 opacity 过渡 + focus-within 同样浮现，键盘 Tab 进行即出操作钮。
  • 当前行高亮降噪：去掉 28% 透明橙描边，改亮一档表面色 + 加强分隔线，EQ 保留为播放语义（唯一保留的循环动画，已加守卫）。
  • 时长码 tabular：等宽表宽数字，列表扫读时纵向对齐。

设置面板

  • 危险色还给销毁：「编辑/添加」全部改中性 ghost 按钮；红色只留给真正的销毁动作。设置页里编辑端点是高频中性操作，用红色既吓退用户又稀释了危险语义。
  • 如实标注保形：「未配置：默认不下载」冒号替换 dash，零默认的诚实口径原样保留。
  • 分组标签正常化：10px 大字距全大写 eyebrow 改 12px/600 正常中文标签；顶栏「完成」从行内样式收进按钮体系。
  • 离线卡改语义底：绿色 ok-soft 底 + 透明边替代自配的绿描边，色值走 token。

媒体库

  • 搜索去光晕：蓝色 3px 外发光改 1px 品牌色聚焦边；聚焦态用边框颜色表达足够，光晕只是噪音。
  • 卡片减动效：hover 上浮 2px 改仅边框加深；play-badge 同步支持 focus-within 触达。
  • 下载态信息升级：「已下载 · 种子离场可续播」从 10px 标题混排改为独立 11.5px 网络语义行；进度「45%」从 sup 角标改为正文行。
  • 海报占位纯色：三档深浅纯色 + 细线胶片字形，网格整体节奏靠色块深浅交替，不再靠渐变云带。

v2.1 复审拍板（2026-10-07）

结论

  • 暗色四页通过，定稿。
  • 亮色版打回重做（本版完成）：v2 亮色版名实不符，外壳仍整面深色。v2.1 把外壳全部主题化：顶栏（白底浅条）、状态徽标与浮层 pill（白底 pill）、注解浮层（白底）、OSC 控制栏（浅色面板 + 深字）、进度槽（浅轨道）；视频画布与其上的字幕属内容层，两主题恒黑，这是真实播放器的正常形态，不算「假亮色」。
  • 小改两项：主播放窗进度槽 4px 加粗到 6px（手柄 10px 到 12px，两主题同步）；左上注解两块合一（信息密度收敛，自动隐藏机制说明保留，一次不糊四块）。
  • 复审范围：重出亮色四页截图 + 主播放窗暗色截图（进度槽同步），其余暗色三页维持原稿。
